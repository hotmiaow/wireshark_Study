Wireshark 必備速查手冊 (Essential Cheat Sheet)

高頻顯示過濾器、邏輯運算子、網路排查秘訣與內建分析工具導引

1. 核心邏輯比較運算子 (Comparison Operators)

運算子中文說明範例過濾表達式
== 或 eq等於 (Equal)ip.src == 192.168.1.1
!= 或 ne不等於 (Not Equal)tcp.port != 80
&& 或 and邏輯且 (Logical AND)ip.addr == 10.0.0.1 && tcp.flags.syn == 1
|| 或 or邏輯或 (Logical OR)dns || http
! 或 not邏輯非 (NOT)!arp && !stp
contains包含特定字串http.request.uri contains "admin"
matches正規表達式匹配 (Regex)http.user_agent matches "(?i)mozilla"

2. 網路故障排查高頻顯示過濾器 (Diagnostic Filters)

故障情境顯示過濾器語法操作
TCP 封包遺失與重傳tcp.analysis.retransmission
TCP 三次重複確認tcp.analysis.duplicate_ack
TCP 零視窗凍結 (接收端卡死)tcp.analysis.zero_window
HTTP 4xx / 5xx 錯誤回應http.response.code >= 400
DNS 解析失敗 (ServFail / NXDomain)dns.flags.rcode != 0
TLS Client Hello (協商發起)tls.handshake.type == 1
SYN 封包 (探測掃描 / SYN Flood)tcp.flags.syn == 1 && tcp.flags.ack == 0
VoIP 網路電話 SIP 呼叫發起sip.Method == "INVITE"
Windows SMB 拒絕存取 (Access Denied)smb2.nt_status == 0xc0000022

3. Wireshark 內建專業排查工具路徑導引

  • Analyze → Follow → TCP / HTTP / TLS Stream：追蹤串流。直接還原發送端與接收端的完整雙向純文字或解密對話內容。
  • Analyze → Expert Information：專家資訊。集中列出所有 Checksum 錯誤、重傳、畸形封包與協議警告。
  • Telephony → VoIP Calls：VoIP 通話分析。自動繪製 SIP 呼叫梯形圖、計算 RTP 抖動與遺失率，並提供內建播放器試聽錄音。
  • Statistics → Protocol Hierarchy：通訊協定階層。以樹狀圖百分比檢視傳輸層、網路層之流量分佈，迅速揪出異常協定。
  • Statistics → Conversations：通訊對話 (Top Talkers)。依 MAC/IP 查看哪兩台主機在短時間內傳輸了最大量封包。
  • Edit → Preferences → Protocols → TLS：TLS 金鑰解密。設定 (Pre)-Master-Secret 金鑰紀錄檔路徑，即可直接解密 HTTPS 流量。
